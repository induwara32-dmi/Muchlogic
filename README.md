# MuchLogic — AI-Focused Software & Web Engineering Agency.

Modern, high-converting, AI-focused software engineering studio homepage for **MuchLogic** (`muchlogic.com`).

Built with **Next.js (App Router), TypeScript, Tailwind CSS, Lucide Icons, and Framer Motion**.

## 🎨 Design System

- **Primary Background:** `#060B19` (Deep Midnight Navy)
- **Secondary Surface / Cards:** `#0D1528` with subtle borders `rgba(59, 130, 246, 0.18)`
- **Primary Brand Accent:** `#2563EB` to `#38BDF8` (Electric Blue gradients, primary CTAs, active glows)
- **Secondary AI Accent:** `#10B981` / `#2DD4BF` (Mint status indicators, badges, micro-highlights)
- **Primary Text:** `#F8FAFC` (Crisp White)
- **Muted Body Text:** `#94A3B8` (Cool Slate)
- **Typography:** `Manrope` (headings, tight tracking `-0.03em`) and `DM Sans` (body copy)

## 🚀 Sections Included

1. **Sticky Glass Navbar** (`Navbar.tsx`): Geometric Electric Blue & Mint icon, wordmark, anchor links, and `Start a Project ↗` CTA.
2. **Hero Section** (`Hero.tsx`): High-impact headline, sub-headline, CTAs, animated radial mesh glow, architectural grid, and floating interactive **AI System Architecture & Live Conversion Dashboard** animation.
3. **About Us Section** (`About.tsx`): 2-column split with `/images/about-ai-visual.png` cyber VR/AI visual, smooth floating Framer Motion animation, floating glass badges (`AI-Native Architecture` and `< 1.0s Load Speed`), and 3 horizontal stat blocks.
4. **Services Bento Grid** (`Services.tsx`): 6-card grid with mouse-tracking Electric Blue & Mint spotlight border hover effects for Web Development, Mobile Apps, UI/UX Design, Custom Software, AI & Automation, and Maintenance & Support.
5. **Featured Case Study** (`CaseStudy.tsx`): Flagship spotlight for **Designkoolama.lk** with key metrics, tech pills, live site link, and an interactive browser mockup preview with working **Dark Mode / Light Mode toggle**.
6. **Editorial Testimonial** (`Testimonial.tsx`): Spotlight quote card from Dineth Pabasara, CEO of Designkoolama (Pvt) Ltd.
7. **Contact & Footer** (`Contact.tsx`, `Footer.tsx`): Accepting new projects badge, direct contact details (Email, WhatsApp, Location), interactive project brief form with service selection, and minimal footer.

## 🛠️ Development & Production

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
